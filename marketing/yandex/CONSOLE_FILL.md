нет. При выборе «Альбомная» SDK сам покажет заглушку «поверните экран».

Рейтинг 12+, а не 0+: в магазине продаётся «Предтрен» — спортивная добавка со
стимулятором. Больше ничего в сборке рейтинг не задевает: ни крови, ни алкоголя,
ни табака, ни мата.

Категории и теги в списке Консоли могут называться иначе — выбирайте ближайшее
существующее, список выше это предложение, а не точные названия из интерфейса.

### Шаг 3. Дополнительные параметры

| Поле | Что ставить |
|---|---|
| Игра использует облачные сохранения | **Да** |
| Отсроченная публикация | Нет |
| Комментарий разработчика | текст ниже |

Облачные сохранения действительно используются: `player.getData` / `setData`
через `getPlayer({ scopes: false })`, то есть и без авторизации игра работает,
а локальный сейв есть всегда.

Комментарий для модерации — можно вставить как есть:

```
Игра на Godot 4.7.1, Compatibility / WebGL 2, threads выключены.

SDK: YaGames.init один раз, LoadingAPI.ready один раз за сессию, GameplayAPI
start/stop только на переходах состояния. game_api_pause / game_api_resume и
visibilitychange ставят игру на паузу и заглушают звук; причины паузы
считаются, звук возвращается только когда ушла последняя.

Реклама: fullscreen только между подходами, не раньше четвёртого закрытого
сета и никогда на первом действии. Rewarded — по желанию игрока, за энергию,
игра полностью проходима без него. На время любой рекламы дерево на паузе и
звук выключен.

Язык берётся из ysdk.environment.i18n.lang: ru/be/kk/uk/uz — русский,
остальные — английский.

Мобильная раскладка включается по ysdk.deviceInfo, а не по наличию тачскрина,
чтобы ноутбук с сенсорным экраном остался десктопом с мышью.

Звук и музыка синтезируются игрой в рантайме, сторонних записей нет.
Шрифт Inter — SIL OFL (подрезан до используемых глифов, что лицензия
разрешает: Reserved Font Name у Inter нет), модели Kenney и WRAD — CC0,
тексты лицензий лежат в сборке и перечислены на экране «Титры» в паузе.

Движок собран своим шаблоном: выключены модули, которых игра не касается
(сеть, XR, навигация, аудиокодеки, импортные кодеки). Это только состав
сборки Godot, исходники движка не патчились.

Лидерборд: технический код mass, значение = масса × 10.
```

## Чего в комплекте нет

Четыре необязательных поля не заполнены, и это осознанно, а не забыто:

- **Maskable иконка** — нужна версия иконки с безопасной зоной под обрезку
  маской. Текущая `icon_512.png` под это не размечена, а обрезать её вслепую
  значит получить срезанный по краям логотип.
- **Обложка на витрину** — отдельный формат под подборки; его размеры есть
  только в подсказке рядом с полем в Консоли, и вслепую их выдумывать не стоит.
- **Вертикальное видео** — игра альбомная, вертикального кадра просто нет.
  Обрезать 16:9 в 9:16 — значит выкинуть 70 % картинки вместе с HUD.
- **Gif-изображение** — дока помечает поле как устаревшее.

Все четыре можно добавить позже, они не блокируют отправку на модерацию.

## Что проверено перед отправкой

Проверено в этой сессии на собранном архиве, Godot 4.7.1:

- `smoke_scene` — PASS; `walk_scene` — `blocked_targets=0`
- Web-сборка в headless Chrome с mock Яндекс SDK:
  `LoadingAPI.ready` ровно один раз, GameplayAPI не трогается в меню и уходит в
  `started` в зале, `game_api_pause` → `stopped` + запись в облако,
  `game_api_resume` → `started`, скрытая вкладка → `stopped` + запись,
  повторное скрытие не дублирует, возврат → `started`
- Страница: `touch-action: none`, `user-select: none`, `overflow: hidden`,
  контекстное меню заблокировано
- Все 19 PNG и 4 MP4 сверены по размеру, формату, кодеку, частоте, длительности

Что **не** проверено и проверяется только на живом черновике:

- **Pointer lock внутри фрейма Яндекса.** Если хост-фрейм его не разрешает,
  мышиный обзор на десктопе не заработает. Это первое, что надо открыть после
  загрузки архива.
- Реальная реклама (в тестах стоял mock), реальный лидерборд, вход в аккаунт
- iOS Safari и физические телефоны

## Лидерборд

Создаётся отдельно от черновика, во вкладке лидербордов:

| Параметр | Значение |
|---|---|
| Технический код | `mass` |
| Тип | числовой, по убыванию |
| Что шлёт игра | `int(масса × 10)` — то есть 128.6 кг уходит как `1286` |

Без созданного лидерборда `setScore` просто молча ничего не делает: игра это
переживает, но таблица в паузе останется пустой.
